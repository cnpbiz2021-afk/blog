# 부천코엔이비인후과 수면클리닉 블로그 웹사이트

부천 수면다원검사, 수면무호흡증, 코골이, 양압기 키워드에 최적화된 모던 원페이지 반응형 블로그 웹사이트입니다.

---

## 🌟 주요 기능 및 특징

1. **SEO 최적화 (구글 / 네이버)**
   - 핵심 타깃 키워드: `부천 수면다원검사`, `부천 수면무호흡증`, `부천 코골이`, `부천 양압기`, `부천코엔이비인후과`, `최성웅 원장`
   - Schema.org `MedicalClinic` / `Physician` JSON-LD 구조화 데이터 적용
   - OpenGraph 및 트위터 카드 소셜 공유 메타태그 완비

2. **히어로 페이지 & 심플 블로그 구조**
   - 상단: 원장님 프로필 사진(`assets/hero-doctor.jpg`) 기반 신뢰감 있는 히어로 배너 + 4대 핵심 수면 진료 요약 바 + 빠른 상담 CTA
   - 하단: 카테고리 구분 없이 최신 글이 직관적으로 나열되는 카드 그리드 피드 + 실시간 검색 + 태그 필터링
   - 상세 읽기 모달 & 원장님 상담 연결 콜아웃 내장
   - 코골이·수면무호흡 자가진단 퀴즈 모달 내장

3. **관리자 로그인 & 글쓰기 시스템 (무서버/정적 호스팅 완벽 대응)**
   - 우측 상단 `관리자` 버튼 클릭 후 비밀번호 입력 (초기 비밀번호: `coen1234!`)
   - 새 글 작성 / 수정 / 삭제 / 썸네일 이미지 첨부(URL 또는 PC 파일 업로드)
   - 데이터 백업(JSON 다운로드) 및 복원(JSON 업로드), 기본 글 초기화 지원

## 🚀 배포 방법 (GitHub Pages & 가비아)

### 1. GitHub Pages 배포 (무료 호스팅)

1. GitHub에 새 저장소(Repository, 예: `bucheon-sleep-clinic`)를 생성합니다.
2. 로컬 프로젝트 파일 전체를 Git으로 커밋하고 푸시합니다:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: 부천 수면다원검사 블로그"
   git branch -M main
   git remote add origin https://github.com/사용자이름/저장소이름.git
   git push -u origin main
   ```
3. GitHub 저장소의 **Settings** → **Pages** 로 이동합니다.
4. **Branch**를 `main` (또는 `gh-pages`) 및 `/ (root)`로 선택하고 **Save**를 클릭합니다.
5. 1~2분 후 `https://사용자이름.github.io/저장소이름/` 주소로 즉시 전 세계에 공개됩니다.

---

### 2. 가비아(Gabia) 도메인 연결 (GitHub Pages 기준)

1. **가비아 도메인 관리 콘솔**에 접속합니다.
2. [DNS 관리] 또는 [DNS 레코드 설정] 메뉴로 이동합니다.
3. 구매한 도메인(예: `coensleep.com`)에 다음 CNAME 또는 A 레코드를 추가합니다:
   - **호스트**: `@` 또는 `www`
   - **타입**: `CNAME`
   - **값**: `사용자이름.github.io.`
4. GitHub 저장소 **Settings** → **Pages** → **Custom domain** 항목에 구매한 도메인(예: `coensleep.com`)을 입력하고 **Enforce HTTPS**에 체크합니다.

---

### 3. 가비아 일반 웹호스팅(FTP) 배포

1. 파일질라(FileZilla) 등 FTP 프로그램을 실행합니다.
2. 가비아 호스팅 FTP 계정으로 접속합니다.
3. `html` (또는 `public_html`, `www`) 폴더 안에 이 프로젝트의 모든 파일(`index.html`, `css/`, `js/`, `assets/`)을 그대로 업로드하면 즉시 웹사이트가 동작합니다.
